## 🎯 Project Overview

MedCare is a comprehensive healthcare management system that connects patients with doctors through an intuitive mobile application backed by a robust REST API.

### **Key Features**

#### 👨‍⚕️ For Patients
- 🔍 Search doctors by specialty and availability
- 📅 Book appointments with real-time queue updates
- 📋 View and manage appointments
- 📄 Upload and manage medical records
- 💊 Access prescriptions
- 🆘 Emergency SOS with location sharing
- 📊 Track vitals history

#### 🩺 For Doctors
- 📊 Dashboard with real-time queue management
- 📆 Manage schedule and availability
- 👥 Patient management with complete history
- 💉 Create and manage prescriptions
- 📈 Analytics and reports
- 🚶 Walk-in/offline patient booking

#### 🛡️ For Admins
- 📊 System overview and analytics
- 👨‍⚕️ Doctor management (CRUD)
- 👤 Patient management
- 📅 Appointment oversight
- ⚙️ System settings
